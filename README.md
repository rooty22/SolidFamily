# صندوق عائلي (Family Fund System)

نظام إلكتروني متكامل لإدارة صندوق العائلة، مبني بمعمارية MVC مخصصة بلغة PHP (بدون أي إطار عمل خارجي)، ويشمل:

- **موقع العميل**: تسجيل حساب (مع تحقق OTP)، تسجيل الدخول، الأسهم والاشتراك الشهري، طلبات الأسهم، مبلغ التأسيس، القروض وطلبات القروض، الإشعارات، الملف الشخصي، الإعدادات.
- **لوحة تحكم الإدارة**: لوحة معلومات وإحصائيات، إدارة المشتركين، الأسهم، طلبات الأسهم، الاشتراكات الشهرية، مبالغ التأسيس، طلبات القروض، القروض والأقساط، عمليات السداد، المعاملات المالية، الإشعارات، رسائل الدعم، محتوى الموقع، إعدادات النظام.

## المتطلبات

- PHP 8.1+ مع امتدادات `pdo_mysql`, `mbstring`
- MySQL 8.0+
- تم تجربة المشروع على بيئة **Laragon** (متوفرة لديك على `C:\laragon`)

## خطوات التشغيل

### 1. إعداد قاعدة البيانات

عدّل بيانات الاتصال إذا لزم الأمر في `config/config.php` (افتراضياً: `root` / `root` على `127.0.0.1`)، ثم نفّذ:

```
php database/migrate.php
php database/seed.php
php database/migrate_pages.php
php database/migrate_settings.php
php database/migrate_page_forms.php
php database/migrate_security.php
php database/migrate_features.php
```

> قاعدة بيانات موجودة مسبقاً؟ شغّل `php database/migrate_security.php` و`php database/migrate_features.php` فقط (آمنان ويمكن تكرارهما): الأول ينشئ جدول `rate_limits` لحماية تسجيل الدخول ورموز التحقق، والثاني يضيف أعمدة الرد على رسائل التواصل ومنع تكرار الإشعارات التلقائية.

هذا سينشئ قاعدة البيانات `sandouk_db` وجميع الجداول، بالإضافة إلى:
- حساب أدمن افتراضي: `admin@sandouk.local` / `Admin@12345`
- إعدادات افتراضية (قيمة السهم، نسبة القرض، ...) وصفحات محتوى (من نحن، الشروط، الخصوصية...)

### 2. تشغيل السيرفر

**الطريقة الأسرع (خادم PHP المدمج مباشرة من المجلد الرئيسي):**

```
php -S localhost:8000 index.php
```
أو إذا كنت تفضل تحديد مجلد الأصول العام:
```
php -S localhost:8000 -t public public/index.php
```

ثم افتح:
- موقع العميل: `http://localhost:8000/`
- لوحة التحكم: `http://localhost:8000/admin/login`

**عبر Laragon / Apache / XAMPP:**
المشروع مهيأ بالكامل للعمل مباشرة برابط نظيف وبدون `/public`:
- إذا كان المشروع في مجلد فرعي: افتح مباشرة `http://localhost/sandouk/`
- إذا كان عبر VirtualHost: افتح `http://sandouk.test/`
- يتم توجيه كافة الطلبات والأصول (CSS/JS/Uploads) تلقائياً، وفي حال تم طلب أي رابط يحتوي على `/public` يتم تحويله تلقائياً بتحويل دائم 301 إلى الرابط النظيف دون إتلاف أي مسارات.

## ملاحظات مهمة

- **رمز التحقق (OTP)**: النظام حالياً في **وضع تجريبي (Stub)** (`otp_stub` في `config/config.php`) — لا يتم إرسال أي رسائل SMS فعلية، ويظهر الرمز (عدد أرقامه `otp_length`، وهو 4 حسب وثيقة المزايا FLD؛ ارفعه إلى 6 لحماية أقوى) في رسالة التنبيه **للطلبات الصادرة من نفس الجهاز فقط** (localhost). عند `otp_stub => false` أو لأي زائر خارجي لا يظهر الرمز أبداً. **قبل النشر الفعلي**: اجعل `otp_stub` = `false` و`debug` = `false`، واربط مزود SMS حقيقي (مثل Unifonic أو Taqnyat) داخل الدالة `OtpCode::deliver()` في `app/Models/OtpCode.php`.
- **الحماية**: 5 محاولات دخول خاطئة لكل حساب (و30 لكل IP) تُقفل الدخول 15 دقيقة، و5 محاولات خاطئة لرمز التحقق تقفله 30 دقيقة، وطلب الرموز محدود بـ 5 كل 15 دقيقة. الجلسة بـ HttpOnly + SameSite=Lax وتُجدَّد عند الدخول.
- **التحقق من الحقول**: كل نموذج يمرّ على `App\Core\Validator` قبل الحفظ (أرقام الجوال تُحوَّل إلى الصيغة `+9665xxxxxxxx`، الهوية 10 أرقام، الآيبان بفحص checksum، المبالغ بحد أقصى خانتين عشريتين، التواريخ الفعلية فقط، دفعات السداد لا تتجاوز المتبقي، وإعدادات النظام تُحفظ كلها أو لا شيء).
- **التصدير (Excel/PDF)**: زر CSV (يفتح مباشرة في Excel) وزر PDF (صفحة طباعة تفتح نافذة الطباعة تلقائياً؛ اختر "Save as PDF") في لوحة المعلومات / عمليات السداد / المعاملات المالية.
- **الإشعارات التلقائية** (تذكير باقتراب موعد الاشتراك، تنبيه التأخر، تذكير/تأخر أقساط القروض): شغّل يومياً `php bin/send_reminders.php` (cron على Linux، أو Task Scheduler على Windows). الإشعار يُرسل مرة واحدة فقط لكل حدث، ويمكن تجربته بـ `--dry-run`. عدد أيام التذكير المسبق الافتراضي 3 ويمكن تغييره بالإعداد `reminder_days_before` في جدول `settings`.
- تسجيل دخول العميل يكون عبر **رقم الهوية الوطنية + كلمة المرور**، وتسجيل دخول الأدمن عبر **البريد الإلكتروني + كلمة المرور**.

## هيكل المشروع

```
app/
  Core/          الأساسيات: Router, Database, Model, View, Auth, Session, Validator
  Controllers/   Admin/ و Site/
  Models/        نماذج قاعدة البيانات
  Views/         admin/ و site/ (تصميم عربي RTL متجاوب)
config/config.php   إعدادات قاعدة البيانات والتطبيق
database/        schema.sql + migrate.php + seed.php
public/          نقطة الدخول (index.php) + الأصول (CSS/JS)
routes/web.php   كل مسارات النظام
```
