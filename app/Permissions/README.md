# باكدج الصلاحيات والأدوار (Roles & Permissions Package)
### مشروع صندوق عائلي (`sandouk`)

منظومة متكاملة وخفيفة لإدارة الأدوار والصلاحيات (RBAC - Role-Based Access Control) مدمجة بالكامل مع معمارية النظام، وتتيح لمدير النظام تعيين صلاحيات دقيقة لأعضاء العائلة أو فريق الإشراف للتحكم فيما يمكنهم رؤيته وتنفيذه على لوحة التحكم الإدارية.

---

## المزايا والوظائف الرئيسية

1. **فصل وتوزيع الصلاحيات (Granular Permissions)**:
   - 30 صلاحية تغطي كافة أقسام ووظائف لوحة التحكم (لوحة الإحصائيات، المشتركون، الأسهم والاكتتاب، الاشتراكات الشهرية، مبالغ التأسيس، القروض والتمويل، السجلات المالية، الإشعارات، رسائل التواصل، المحتوى والترجمة، إعدادات النظام، وإدارة الصلاحيات).

2. **قوالب أدوار قياسية جاهزة للاستخدام الفوري**:
   - **المدير العام (`super_admin`)**: صلاحيات كاملة ومطلقة بدون أي قيود.
   - **أمين الصندوق (`treasurer`)**: المسؤول المالي (إدارة الاشتراكات، مبالغ التأسيس، الأقساط، الدفتر المالي وعمليات السداد).
   - **لجنة القروض والتمويل (`loans_committee`)**: مراجعة طلبات القروض، اعتمادها أو رفضها، ومتابعة سجل القروض.
   - **مسؤول شؤون المشتركين والأسهم (`membership_officer`)**: إضافة الأعضاء، تعديل البيانات، إدارة الأسهم والاكتتاب.
   - **مشرف المحتوى والتواصل (`support_officer`)**: الرد على الرسائل، إرسال الإشعارات، وتعديل الصفحات ومحتوى الموقع.
   - **مراقب الحسابات (`auditor`)**: صلاحيات تدقيق واطلاع وتصدير تقارير دون إمكانية التعديل.
   - إمكانية **إنشاء أدوار مخصصة لا حصر لها** مع اختيار الصلاحيات الفردية المناسبة.

3. **تعيين الصلاحيات لأعضاء الصندوق (Member Dashboard Access)**:
   - يمكن للأدمن تفويض أي عضو من أعضاء الصندوق ليكون مشرفاً على لوحة التحكم.
   - يتم تعيين الدور الوظيفي للعضو بضغطة زر (سواء من صفحة «الأدوار والصلاحيات» أو مباشرة من نموذج تعديل العضو).
   - بمجرد التفويض، يمكن للعضو تسجيل الدخول إلى لوحة الإدارة (`/admin/login`) باستخدام **رقم هويته الوطنية أو بريده الإلكتروني وكلمة مروره الخاصة**.
   - يتم وسم حساب العضو تلقائياً كحساب إداري معفى من القروض لمنع تضارب المصالح المالية.
   - عند سحب الصلاحيات من العضو، يتم إيقاف وصوله للوحة التحكم فوراً وإعادته كعضو عادي.

4. **حماية ثلاثية الطبقات (Triple-Layer Security)**:
   - **واجهة المستخدم (UI Layer)**: إخفاء القوائم، الأزرار، والبطاقات غير المصرح بها تلقائياً.
   - **الوسيط البرمجي (Middleware Layer)**: حماية المسارات برمجياً وفحص الصلاحيات قبل توجيه الطلب.
   - **طبقة التحكم (Controller Layer)**: دوال فحص داخلي (`$this->authorize(...)`) لمنع أي تلاعب بالطلبات أو نماذج الـ POST.

## التفعيل وتهيئة قاعدة البيانات

شغّل أمر الترقية التالي (آمن ويمكن تكراره دون أي ضرر على البيانات الحالية):

```bash
php database/migrate_permissions.php
```

يقوم هذا السكربت تلقائياً بـ:
1. إنشاء جداول: `roles`, `permissions`, `role_permissions`, `admin_roles`, `admin_permissions`.
2. إضافة عمود `member_id` لجدول `admins` للربط المحكم دون أي كسر للمفاتيح الأجنبية (Foreign Keys).
3. غرس كافة الصلاحيات الأساسية والأدوار القيادية المعتمدة.
4. ترقية حساب الأدمن الأساسي إلى دور «المدير العام».

## الاستخدام البرمجي في الكود (Developer Guide)

### 1. فحص الصلاحيات في ملفات العرض (Views / Blade / Blade-like PHP):
```php
<?php if (admin_can('loans.create')): ?>
    <a href="<?= url('admin/loans/create') ?>" class="btn btn-primary">إنشاء قرض جديد</a>
<?php endif; ?>

<?php if (admin_can('settings.manage')): ?>
    <!-- قسم إعدادات النظام -->
<?php endif; ?>
```

### 2. فحص الأدوار:
```php
<?php if (admin_has_role('treasurer')): ?>
    <!-- مخصص لأمين الصندوق -->
<?php endif; ?>

<?php if (admin_is_super()): ?>
    <!-- مخصص للمدير العام فقط -->
<?php endif; ?>
```

### 3. حماية المسارات في `routes/web.php`:
```php
$router->get('/loans/create', [LoansController::class, 'create'], [Middleware::permission('loans.create')]);
$router->post('/loans', [LoansController::class, 'store'], [Middleware::permission('loans.create')]);
```

### 4. الفحص داخل وحدات التحكم (Controllers):
```php
public function destroy(string $id): void
{
    $this->authorize('members.delete');
    // ... logic
}
```

### 5. تعيين الصلاحيات أو سحبها برمجياً:
```php
use App\Permissions\PermissionManager;

// منح العضو رقم 5 دور أمين الصندوق (Role ID: 2)
PermissionManager::grantMemberDashboardAccess($memberId = 5, $roleId = 2);

// سحب كافة الصلاحيات الإدارية من العضو
PermissionManager::revokeMemberDashboardAccess($memberId = 5);
```

## شاشة إدارة الأدوار في لوحة التحكم

يمكن الوصول إليها عبر القائمة الجانبية: **النظام والصلاحيات** ← **الأدوار والصلاحيات** (`/admin/roles`).
تحتوي على:
- تبويب **الأعضاء والمشرفون المفوّضون**: عرض جميع الأعضاء الحاصلين على صلاحيات، دور كل منهم، عدد صلاحياته، وزر لتعديل أو سحب الصلاحيات، بالإضافة لزر «تعيين صلاحيات لعضو».
- تبويب **الأدوار وقوالب الصلاحيات**: عرض بطاقات الأدوار، عدد المفوّضين بكل دور، زر تعديل مصفوفة الصلاحيات، وزر إنشاء دور جديد.
